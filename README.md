# 字幕节奏校对台（Subtitle Rhythm Deck）

一个完全在本地 / 浏览器内运行的字幕时间轴校对工具：导入 **SRT 字幕** 与**浏览器可播放的音频**，
在同一时间轴上拖动字幕块的左右边界校准节奏。拖动时实时强制 **不重叠 / 最短时长 / 最小间隔** 三条约束，
越界操作会**自动回弹并标出原因**。

- React 18 + TypeScript + Vite，纯前端、无后端、无外部服务
- 字幕与音频均通过浏览器本地读取，**不会上传任何文件**
- Nginx 静态镜像 + Docker Compose 一键启动

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 导入 SRT | 兼容 `,` / `.` 毫秒分隔符、缺序号块、CRLF；解析异常逐块告警不中断 |
| 导入音频 | 任意浏览器原生可播放格式（mp3 / wav / m4a / aac / ogg / opus 等） |
| 本地静音分析 | 音频加载后用 **Web Audio API** 本地解码（不上传），按 **20ms 窗口**计算各声道 RMS 的最大值；低于可调阈值且连续 **≥200ms** 才形成静音段，间隔 **<80ms** 的段先合并 |
| 静音带叠加 | 静音段以斜纹带叠加在标尺与泳道上，拖动吸附命中的段会高亮 |
| 静音吸附 | 拖动字幕边界进入静音段边缘 **150ms** 范围即吸附到最近边缘，两侧等距取更早者；吸附结果仍须通过最短时长 / 最小间隔校验，不合法时**保留未吸附候选并提示原因**；工具栏提供吸附开关与可调阈值（dB） |
| 时间轴校对 | 拖动字幕块**左/右边界**手柄调整起止时间，毫秒级吸附（1ms） |
| 区间漂移校准 | 字幕列表 **Shift+点击** 选连续区间，以「首条起点 / 末条终点」为原始锚点输入目标时间，区间内全部起止时间做同一**线性映射**；时间轴实时预览旧/新位置与缩放比例；锚点倒序、映射后低于最短时长、相邻间隔不足即**禁止提交并定位首个冲突**；合法结果作为一次历史记录整体撤销/重做 |
| 三重约束 | 实时校验：不可与相邻字幕重叠、不短于「最短时长」、不小于「最小间隔」、不可越过 0s |
| 越界回弹 | 非法位置松手后块原样回弹，显示红色虚影 + 气泡说明具体原因（与上/下一条、差多少毫秒） |
| 约束参考线 | 拖动时黄色虚线标出当前边界允许的活动区间 |
| 点击定位播放 | 点击字幕块或列表中的时间码即跳转并播放；点击标尺/空白轨道定位播放头 |
| A-B 循环试听 | 以选中字幕起止 ± 可调前后余量形成循环区间，播放越过 B 点自动回到 A 点；切换选择保留开关并更新区间，播放头落在新区间外立即跳到新 A 点；时间轴标出 A/B 旗标与循环范围；无音频 / 未选字幕 / 区间裁剪后为空时禁用并说明原因 |
| 单句跟读对比 | 选中字幕并导入音频后一键跟读：申请麦克风 → 页面倒计时 3 秒 → **先启动麦克风录音、再从字幕起点播放原音**，到字幕终点（裁剪到音频结尾）自动停止；**录音只以 Blob URL 保存在当前浏览器会话内存中，不上传、不落盘**。回放时原音与录音同步启动，两轨各自独立的音量与静音控制；任一路暂停 / 结束 / 重新定位都联动另一轨，累计时钟偏差超过 **80ms** 即以原音时钟纠偏。录制期间自动暂停 A-B 回卷（开关状态保留，结束自动恢复）；切换字幕、导入新音频、重新录制或离开页面都会停止并释放旧 `MediaStream`、定时器与 Object URL；权限被拒 / 设备缺失 / 浏览器不支持均给出可恢复提示 |
| 撤销 / 重做 | 仅记录成功的边界调整；`Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z`（或 `Ctrl+Y`）重做 |
| 缩放 | 滑块在 10–400 px/s 之间无级缩放，横向滚动浏览 |
| 约束可调 | 工具栏实时修改最短时长与最小间隔（秒），立即对后续拖动生效 |
| 导出 SRT | 按时间先后重排并输出连续编号 `1..N`，文件名为 `<原名>.fixed.srt` |

> 说明：本工具专注「节奏」校对，即只调整时间码，不编辑字幕文本。

## 一键启动（Docker Compose）

需要 Docker 20.10+ 与 Compose v2。

```bash
docker compose up -d --build
```

| 入口 | 地址 |

| 本地生产预览 | http://localhost:4173 （`npm run preview`） |


## 使用步骤

1. 打开页面后点击 **导入 SRT**，选择字幕文件（解析告警会出现在右下角）。
2. 点击 **导入音频**，选择与字幕配套的音频。加载后会自动用 Web Audio API 解码并检测静音段（状态栏显示「静音分析中… / N 段静音」）；**更换音频会取消旧分析，旧结果不会回写**。
3. 用滑块调整合适缩放；鼠标悬停边界手柄可看到允许拖动范围。时间轴上的斜纹带即静音段。
4. 按住字幕块的**左/右手柄**拖动：
   - 边界进入静音段边缘 **150ms** 内时自动吸附（绿色吸附线 + 气泡），两侧等距取更早边缘；
   - 吸附点若违反最短时长 / 最小间隔 / 重叠约束，则**不采用吸附**，保留未吸附候选，并以气泡与提示条说明原因；
   - 合法位置松手 → 边界更新并进入撤销历史；
   - 非法位置松手 → 块回弹，红色虚影与气泡标明原因（重叠 / 间隔不足 / 时长不足 / 越过 0s）。
5. 工具栏可勾选/取消 **静音吸附** 开关，并用 **阈值（−60 ~ −20 dB）** 滑块调整静音判定电平；调阈值只对当前音频重新分段，无需重新解码。
6. 点击字幕块本体或左侧列表时间码，播放头跳到该字幕并开始播放。
7. 选中一条字幕后可开启工具栏的 **A-B 循环**：循环区间为「字幕起点 − 前余量 → 字幕终点 + 后余量」（余量可实时调整，A 不越过 0s、B 不越过音频结尾）；播放越过 B 点自动回到 A 点继续。切换选择时循环开关保留、区间随之更新，播放头落在新区间外会立即跳到新 A 点；暂停、导入新音频或关闭循环后，旧的播放回调不会再拉回播放头。未导入音频、未选字幕或区间经音频时长裁剪后为空时，开关禁用并显示原因。
8. **区间漂移校准**（批量平移/拉伸连续字幕）：在字幕列表普通点击一条字幕设定锚点，再 **Shift+点击** 另一条字幕选中连续区间（再次普通点击可收起）。下方出现「区间漂移校准」面板，以区间**首条起点、末条终点**为原始锚点，输入各自的**目标时间**（支持 `83.5`、`01:23.500`、`00:01:23,500` 等格式）后，区间内所有起止时间做同一线性映射。输入过程中时间轴实时显示**旧位置（半透明原块）/ 新位置（虚影）预览与缩放比例**；目标锚点倒序、映射后任一字幕低于当前最短时长、或与区间内外相邻字幕不满足最小间隔时，**应用按钮禁用并自动定位首个冲突**（红色预览 + 冲突气泡，可点「定位」再次跳转）。点击 **应用映射**（或 Enter）将合法结果作为**一次历史记录**提交，可整体撤销/重做并随现有流程导出 SRT；点击 **取消**（或 Esc）、切换字幕/音频文件都会清空区间与预览。
9. 快捷键：`空格` 播放/暂停，`Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z` 重做（跟读录音进行中空格与时间轴点击会被暂时屏蔽）。
10. 舞台底部的 **🎤 单句跟读对比** 面板用于逐句模仿：
   - 选中一条字幕并已导入音频后点击 **开始跟读**：浏览器申请麦克风权限，随后页面 **倒计时 3 秒**；倒计时结束后**先启动麦克风录音，再从字幕起点播放原音**，到达字幕终点（自动裁剪到音频结尾）即停止，也可点 **提前停止** 落盘较短录音；
   - 录音完成后进入双轨回放：原音轨与录音轨**同步启动**，每轨有独立的音量滑块与静音按钮；
   - 任一路暂停 / 播放到结束 / 拖动进度条，另一轨都会联动；两轨累计时钟偏差超过 **80ms** 时自动以**原音时钟**把录音轨拉回对齐（面板右上角显示实时偏差）；
   - 可 **重新录制**（先释放旧录音的 MediaStream / 定时器 / Object URL 再开新一轮）或 **丢弃**；
   - **录音仅保存在当前浏览器会话内存中**（Object URL），刷新或关闭页面即消失，不会写入磁盘或上传；
   - 录制期间 A-B 回卷自动暂停（工具栏开关保持原状并显示「跟读录音中 · 已暂停回卷」），录音结束后按原开关状态恢复；切换字幕、导入新音频也会立即停止并释放旧录音资源；
   - 浏览器不支持录音、麦克风权限被拒绝、无设备或设备被占用时，面板显示具体原因，处理后可在原处 **重试**。
11. 点击 **导出 SRT**，得到按时间顺序重新编号的校对结果。

## 静音检测与吸附的精确定义

- **窗口能量**：解码后按 `20ms` 窗口遍历，对每个声道计算 RMS，窗口能量取**各声道 RMS 的最大值**（任一声道有声即不算静音）。
- **成段条件**：窗口能量**严格低于**阈值的连续窗口形成候选段；连续时长 **≥ 200ms** 才保留（恰好 200ms 合法）。
- **段合并**：两个候选段之间的非静音间隔 **< 80ms** 时先合并为一段（恰好 80ms 不合并），合并后再过最短时长过滤。
- **吸附规则**：边界原始候选时间 `t` 在某静音段边缘（段起点或段终点）**150ms 半径内**（严格小于）才吸附；取距离最近的边缘，距离相等时取时间更早者。
- **吸附校验**：吸附后的时间必须与未吸附候选走**同一套**约束校验（不重叠 / 最短时长 / 最小间隔 / ≥0）。吸附点合法则采用吸附；吸附点不合法则保留未吸附候选，并返回吸附点的具体违规原因。

## A-B 循环的精确定义

- **区间**：`A = max(0, 字幕起点 − 前余量)`，`B = min(字幕终点 + 后余量, 音频时长)`（时长未知时不裁剪 B）；余量负值按 0 计；`B − A < 0.05s` 视为空区间，循环不可用。
- **回卷**：循环激活且播放中，帧级监听发现 `currentTime ≥ B` 即跳回 A 继续播放；B 恰好等于音频结尾时由 `ended` 事件回卷。
- **进入**：开启循环或切换选择时，播放头落在 `[A, B]` 之外立即跳到新 A 点（保持当前播放/暂停状态）；落在区间内则不移动；仅调整余量不抢播放头。
- **失效**：暂停、导入新音频、关闭循环都会同步作废旧循环计划并取消帧监听，此后任何已排队的播放回调都不会再改动播放头。
- **禁用**：无音频、未选字幕、区间经音频时长裁剪后为空，三者任一成立即禁用开关并显示原因；已开启的循环进入待机，条件恢复后自动续用。

## 单句跟读对比的精确定义

- **录音时序**：点击「开始跟读」后先在用户手势链中 `getUserMedia` 申请麦克风（开启回声消除 / 降噪 / 自动增益），权限成功才显示 **3 秒** 倒计时；倒计时结束时**先** `MediaRecorder.start()`，**再**把独立原音轨 seek 到字幕起点并 `play()`（两轨使用各自独立的 `<audio>` 元素，不干扰主导航）。
- **自动停止**：录音区间终点为 `min(字幕终点, 音频时长)`（且与起点至少留 50ms）；帧级监听发现原音到达终点即暂停并 `recorder.stop()`；终点恰为音频结尾时由原音 `ended` 事件兜底（两路径幂等去重）。
- **存储范围**：录音分片聚合成 Blob 后只通过 `URL.createObjectURL` 生成内存 URL 供回放，不写 IndexedDB / localStorage / 文件；切换字幕、导入新音频、重新录制、丢弃或组件卸载时 `revokeObjectURL` 并停止释放全部 MediaStream 轨道。
- **双轨回放**：进入回放阶段时释放麦克风；原音与录音相对时间 1:1 映射（录音时长以其自身 metadata 为准，缺失时用区间长度兜底）。
- **联动**：任一路 `play` / `pause` 都带动另一轨同状态；任一路自然结束则两轨一起复位到起点；任一路被重新定位，另一轨 seek 到同一相对位置（`seeked` 为异步事件，用「对轨位置是否已对齐」而非同步标记来避免事件回环）。
- **纠偏**：回放期间以 rAF 读取两轨位置，偏差 `原音相对位置 − 录音位置` 的绝对值**严格大于 80ms** 时把录音轨重新定位到原音对应位置（恰好 80ms 不纠偏）。
- **与 A-B 循环的关系**：倒计时与录音期间强制使 A-B 回卷计划失效（同步置 inactive 并取消帧监听），但不改动用户的开关与余量设置；忙碌结束后若开关仍开启且区间有效，回卷自动恢复。
- **失败提示**：缺少 `getUserMedia` / `MediaRecorder` 判为浏览器不支持；`NotAllowedError` / `SecurityError` 提示去地址栏授权；`NotFoundError` / `OverconstrainedError` 提示检查设备；`NotReadableError` 提示设备被占用——除不支持外均提供原位「重试」。

## 区间漂移校准的精确定义

- **区间选择**：字幕列表普通点击设定锚点，**Shift+点击**另一行选中锚点到该行之间的连续区间（含两端，自动按时间排序，与点击先后无关）；再次普通点击任意行收起区间。锚点 id 失效（如切换文件）时区间自动作废。
- **锚点与映射**：原始锚点为区间**首条起点** `oldStart` 与**末条终点** `oldEnd`；输入目标起点 `newStart`、目标终点 `newEnd` 后，区间内所有起止时间 `t` 映射为
  `t' = newStart + (t − oldStart) × scale`，其中 `scale = (newEnd − newStart) / (oldEnd − oldStart)`。
  映射结果统一**四舍五入到毫秒**后再校验，保证「预览所见即提交所得」；区间外字幕保持原样。
- **预览**：输入可解析即实时预览——时间轴上原块半透明显示旧位置、虚影块显示新位置，并标出新锚点线与缩放比例（面板同步显示缩放与起点平移量）；存在冲突时预览整体变红、首个冲突字幕的虚影与列表行高亮。
- **禁止提交**（按时间序取**首个**冲突并自动定位到对应字幕）：
  1. 目标锚点非法（负值 / 无法识别）或原始区间长度为零；
  2. 目标锚点倒序：`newEnd ≤ newStart`；
  3. 映射后任一区间内字幕时长 **< 当前最短时长**；
  4. 与相邻字幕（区间内外，至少一端在区间内）间隔 **< 当前最小间隔**（重叠按负间隔一并报出）。
  时长 / 间隔**恰好等于**下限合法。两端都在区间外的相邻对未被映射改动，不参与冲突判定。
- **提交与历史**：仅在无冲突时可提交；合法结果作为**一次历史记录**进入撤销栈，`Ctrl/⌘+Z` 整体撤销、`Ctrl/⌘+Shift+Z` 重做，导出 SRT 走现有流程（按时间重排并连续编号）。
- **清空**：切换字幕 / 音频文件、点击「取消」或按 Esc 都会清空区间与预览；撤销 / 重做不清空预览，原始锚点跟随最新数据实时重算。

## 约束规则的精确定义

设被调整字幕为 `C`，时间轴上相邻的上一条为 `P`、下一条为 `N`：

- 拖动左边界到 `s` 时必须满足：
  `s ≥ 0`、`s ≤ C.end − 最短时长`、
  `P` 存在时 `s ≥ P.end + 最小间隔`（该条件同时排除了重叠）。
- 拖动右边界到 `e` 时必须满足：
  `e ≥ C.start + 最短时长`、
  `N` 存在时 `e ≤ N.start − 最小间隔`。
- 任一条件不满足则不修改数据（回弹），并返回第一条被违反规则的说明。
